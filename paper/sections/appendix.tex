\section{Gold Rules per Collection}
\label{app:gold}

Gold evidence is placed in each parser's text by exact match, then by a
normalised match that ignores case, whitespace, quote and dash style and
table or LaTeX notation, and only then by a fuzzy match. Exact and
normalised placements are \emph{certain}; fuzzy placements are flagged and
dropped by a rule frozen before scoring. When evidence occurs more than
once, the page named by the collection decides; without a page guide a
repeated span is not used. Per collection: a CUAD answer is kept only if
it occurs once in its contract; OHR-Bench keeps text and table evidence;
QASPER uses the union of its annotators' text evidence; FinanceBench uses
the text of each evidence item, searched in the whole document;
UniDoc-Bench has page-level gold only and is not scored; the Indian
questions use their evidence strings. Held-out gold was built with the
same code before any held-out scoring, and the tuning gold stayed
byte-identical.

\section{Scorer Rules}
\label{app:scorer}

The rules below restate the code of \texttt{scorer\_v1} (tagged; the file
is unchanged since). BM25 ranks chunks on lower-cased word tokens with
$k_1=\BMKone{}$ and $b=\BMb{}$ and the Okapi inverse document frequency
with add-one smoothing inside the logarithm, so it is never negative. Dense retrieval ranks by the cosine
similarity of cached bge-m3 vectors. The hybrid ranking is reciprocal rank
fusion with $k=\RRFk{}$. Ties keep the chunk order. A ranking is read
until the token budget is used: each chunk's prefix tokens are counted,
text already read is skipped, so overlap is counted once, and the last
part is cut at the budget by the tokenizer's offsets. Gold pieces of a
question are merged where they overlap and counted in non-whitespace
characters. Recall@B is the share of gold characters inside the text
read; Hit@B means at least one gold character was read, and Full@B means
all were. MRR uses the first chunk that holds any gold character.

\section{Answer Judge Check}
\label{app:judge}

The judge was checked against one human rater on \JudgeCases{} cases. At
the first pass agreement was \ManualJudgeFirstPassAgreement{}\% (recorded
$\kappa=\ManualJudgeFirstPassKappa{}$), below the pre-set threshold;
\ManualJudgeFirstPassLongCorrect{} of the
\ManualJudgeFirstPassDisagreements{} disagreements were long but correct
answers that the human scored as partly and the judge as fully correct,
as the judge's guide prescribes. A second, non-blind reading of the
\JudgeDisagreements{} disagreements gave \JudgeSecondAgreement{}\%
($\kappa=\JudgeSecondKappa{}$). The first-pass labels were overwritten
by the second pass, so the recorded first-pass values cannot be
recomputed; a reconstruction from the second-pass file gives
$\kappa=\JudgeReconKappaLow{}$--$\JudgeReconKappaHigh{}$. The
\JudgeCases{} cases were drawn as one sample, so the size of the check
was fixed before any case was labelled; the frozen design had named a
smaller check, and no note gives a reason for the change. The switch of
judge to Qwen3-8B was first committed together with the result, and the
check has no run record, so the record cannot show that the switch
preceded the check.

\section{Scorer Sanity Tests}
\label{app:sanity}

Before the scorer was frozen, two tests checked that it punishes damage.
\emph{Floor:} random cuts scored \SanityFloorLower{} lower than the best
setting in each of the \SanityFloorCases{} parser and retriever cases.
Under the rule written before the run (non-overlapping separate
intervals) the test failed in \SanityFloorFailedOriginal{} of
\SanityFloorCases{} cases, because separate intervals over the documents
mostly measure how documents differ. Under the paired rule, amended
before any held-out result, it passed in every case; this re-analysis is
recorded in the specification only. \emph{Damage:} splitting every table
lowered recall on \SanityDamageQuestions{} table questions from
\SanityDamageDocuments{} Docling documents by \SanityDamageDrop{} and
changed the other questions by at most \SanityDamageOtherMax{}; the test
passed for \SanityDamagePassed{} of \SanityDamageCases{} retrievers.
