% Outside the page limit. No new experiments, figures or analyses.

\paragraph{Data and licences.} All documents are public: contracts,
scientific papers, public reports and filings, government regulations
and scanned documents from public benchmarks. They contain no personal
data that we collected. Two sources, UniDoc-Bench and the FinanceBench
annotations, are licensed CC BY-NC 4.0, which covers research use; files
derived from them keep the attribution and non-commercial terms. The
repository's NOTICE file lists, for every source, its licence and each
distributed file that contains its text, and marks licences we could not
find as unknown. Model answers written from documents of unknown licence
are not distributed (Appendix~\ref{app:datasets}).

\paragraph{Models and compute.} An LLM (gemini-3.5-flash-lite) proposed
split patterns for one chunker and wrote the answers for RQ4; an
open-weight model (Qwen3-8B) judged them. The compute is listed in
Appendix~\ref{app:compute}.

\paragraph{AI assistance.} Claude (Anthropic) helped draft the text and
build the code of this study. The author checked all text, code and
numbers and is responsible for the content.
