\section{Conclusion}\label{sec:conclusion}

We asked whether choosing a parse-and-chunk setup per PDF improves retrieval
over one fixed setup. On two sealed held-out sets, under a fixed token budget
and a decision rule written in advance, a cross-fitted per-document oracle
did not beat the best single setup, and we find no evidence of a gain from
per-document choice. Small chunks tend to retrieve best at a fixed budget,
the ranking reverses when the number of chunks is fixed instead, and tuning
matters mainly where a library default is far off. We release the code, the
locked results and a tool with fixed defaults, so that these findings can be
checked and extended.
